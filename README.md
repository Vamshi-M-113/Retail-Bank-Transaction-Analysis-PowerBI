# 📊 Retail Bank Transaction Analysis | Power BI

## 📌 Project Overview

This project focuses on analyzing retail banking data using **Power BI** to understand customer activity, accounts, loans, payments, transactions, and branch performance.

I cleaned and transformed the data, created a data model and DAX measures, and built an interactive dashboard to present key business insights.

## 🛠️ Tools Used

- Power BI
- Power Query
- DAX
- Data Cleaning
- Data Modelling
- Data Visualization
